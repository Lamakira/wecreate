# Use Mux for public video

Portfolio and hero videos will use Mux for transcoding, adaptive streaming, generated playback assets, and aggregate quality analytics, while Sanity owns their editorial metadata and associations. This adds a specialist video vendor but avoids serving fixed-quality CMS files to variable mobile connections in Benin; playback is capped at 1080p, mobile starts from posters, and autoplay is disabled for Save-Data or reduced-motion users.
